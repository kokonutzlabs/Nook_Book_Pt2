# Digital Forensic Analysis of Warehouse Shipment Records

## Overview
This project simulates a digital forensic investigation of warehouse shipment data using Python and SQLite. It focuses on identifying tampered, incomplete, or non-compliant records, including weight discrepancies, timestamp manipulation, missing audit logs, and SOP/GMP violations.

## Key Features
- Shipment and audit log analysis
- Timeline reconstruction
- Data integrity validation
- Anomaly detection
- SOP/GMP compliance checks
- Forensic reporting and evidence summaries
